# ✨ Sokimium Ultimate Hub

## 🎮 О проекте
**Sokimium** — это современное приложение для Windows, объединяющее в себе классные мини-игры, полезные инструменты под рукой и безопасную систему авторизации через Telegram-бота.

### 🌟 Что внутри:
* **Игровой зал:** Кликер очков с прокачкой, «Угадай число», классические Крестики-Нолики против умного бота, Угадай стаканчик и полноценная мини-Змейка!
* **Полезные всячины:** Генератор надежных паролей, тест реакции в миллисекундах, умный калькулятор и рандомайзер чисел.
* **Личные заметки:** Сохраняйте свои записи, привязанные к вашему аккаунту.
* **Безопасность:** Вход по цифровому Telegram ID с подтверждением через секретный код в боте.
* **Настройки:** Изменение тем оформления (Dark / Light) и размеров окна «на лету».

---

## 📥 Как установить
1. Перейдите в раздел **Releases** справа на странице.
2. Скачайте свежий установщик **`SokimiumSetup.exe`**.
3. Запустите его и следуйте инструкциям на экране (программа автоматически установится и создаст ярлык на рабочем столе).
